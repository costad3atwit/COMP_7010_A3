# COMP_7010_A3
Linear Programming Assignment
reference tutorial video: https://www.youtube.com/watch?v=wdUfeK8cyys

## To run this code
1. Create a python virtual environment at the repository root and activate it with:
    - `python -m venv venv`
    - `source venv/bin/activate`
2. Install the assignment dependencies:
    - `pip install -r requirements.txt`
3. Run the tests and show print output
    - `pytest -s a3.py`
